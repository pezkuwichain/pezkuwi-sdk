## Pending Manual Steps

These steps require external interaction and cannot be automated:

### Step 1: Obtain ROC Tokens ⏳
- **Action**: Visit Rococo faucet
- **URL**: https://paritytech.github.io/polkadot-testnet-faucet/
- **Required**: ~50-100 ROC
- **Purpose**: ParaId reservation and deposits

### Step 2: Reserve ParaId ⏳
- **Action**: Reserve parachain ID on Rococo
- **URL**: https://polkadot.js.org/apps/?rpc=wss://rococo-rpc.polkadot.io#/parachains/parathreads
- **Navigation**: Network → Parachains → Parathreads → Reserve ParaId
- **Cost**: ~40 ROC deposit
- **Note**: Save your assigned ParaId (e.g., 4242)

### Step 3: Register Parachain ⏳
- **Action**: Submit parachain registration to Rococo
- **Method**: Use `deploy-to-rococo.sh` to generate registration info
- **Tool**: Polkadot.js Apps → Developer → Sudo
- **Extrinsic**: `parasSudoWrapper.sudoScheduleParaInitialize()`
- **Required Files**: `pezkuwi-genesis-state.hex`, `pezkuwi-runtime.wasm.hex`

### Step 4: Start Collator Node ⏳
- **Action**: Launch Pezkuwi collator
- **Command**: See `deployment-info.txt` (generated by script)
- **Requirements**:
  - Synced Rococo relay chain connection
  - Minimum 2 CPU cores, 4GB RAM
  - 50GB disk space
  - Stable network connection

### Step 5: Open HRMP Channel ⏳
- **Action**: Establish channel with Asset Hub (Para 1000)
- **Method**: XCM Transact message via `xcmPallet.send()`
- **Configuration**:
  - Max capacity: 1000 messages
  - Max message size: 102400 bytes
- **Wait**: Asset Hub must accept channel

### Step 6: Test XCM Transfer ⏳
- **Action**: Execute test USDT → wUSDT reserve transfer
- **Source**: Asset Hub USDT
- **Destination**: Pezkuwi wUSDT
- **Amount**: Small test amount (e.g., 10 USDT)
- **Verification**: Check ForeignAssets balance on Pezkuwi
